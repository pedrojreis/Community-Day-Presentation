# A Home for Everyone

Six-slide lightning presentation for Open Home Foundation Community Day in Lisbon on 6 November 2026.

View the presentation on [GitHub Pages](https://pedrojreis.github.io/Community-Day-Presentation/).

Open `index.html` in a browser to present. Use the left and right arrow keys to navigate, `F` for fullscreen, `S` for Presenter View (English controls, speaker notes, and timer), `O` for slide overview, and `T` to cycle themes. The local `implementation.mp4` file is embedded on slide 2 and automatically plays (muted, looping) when you enter the slide.

The default `home-assistant` theme (`assets/themes/home-assistant.css`) uses Home Assistant's official dark-mode colour tokens. `community-day-2026.png` is the official Community Day 2026 badge.

## Projects featured

Slides 3–5 showcase these open-source Home Assistant dashboard projects:

- [Homio](https://github.com/iamtherufus/Homio) by iamtherufus
- [Homie Dashboard](https://github.com/Big-Edge2297/homie-dashboard) by Big-Edge2297
- [Home Assistant Tablet Dashboard](https://github.com/NathanLenias/Home-Assistant-Tablet-Dashboard) by NathanLenias

The slides include project screenshots (`assets/screenshots/*.png`), comparison details, and QR codes (`qr/*.svg`). Slide 6 includes a QR code (`qr/presentation.svg`) linking to the live presentation.

GitHub Pages publishes the repository root from `main`. Push changes to `main` to update the live presentation; `.nojekyll` keeps these static files served without Jekyll processing. The repository and published presentation, including the video, are public.
