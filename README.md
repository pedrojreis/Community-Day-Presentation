# A Home for Everyone

Four-slide presentation for Open Home Foundation Community Day in Lisbon on 6 November 2026.

Open `index.html` in a browser to present. Use the left and right arrow keys to navigate, `F` for fullscreen, `O` for slide overview, and `T` to cycle themes. The local `implementation.mp4` file is embedded on slide 2.

The default `home-assistant` theme (`assets/themes/home-assistant.css`) uses Home Assistant's official dark-mode colour tokens. `community-day-2026.png` is the official Community Day 2026 badge.
